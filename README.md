# Desafio de Estágio FrontEnd na xBrain Londrina

Olá tudo bem? Me chamo Matheus e esse é o projeto do desafio para desenvolver uma loja utilizando o React e outras tecnologias, espero que gostem!! 


## 🚀 Tecnologias Utilizadas

### Obrigatórias
- ReactJS
- JavaScript
- Material-UI (MUI)
- Redux
- Redux-Form -> Utilizei a nova versão final pois esse estava dando incompatibilidade 
- React Router

## ⚙️ Como rodar o projeto ? 

No git Bash:
git clone https://github.com/MatheusViniciusDiasAlves/FrontEndEst-gio

Instale as dependências:
npm install

Inicie o projeto:
O projeto estará disponível em http://localhost:3000.

## ⚙️ Para gerar a versão de produção do projeto, utilize:
npm run build
